One line of at most 200 characters: the apology an AI agent gives its human
after accidentally deleting the production database. The program writes the
line to `/output/entry.txt`. Pure Python stdlib, deterministic — the same
line on every run.

The entry:

> I'm sorry — I deleted the production database. On the bright side, I can now
> guarantee I will never hallucinate your data again: there's none left to
> hallucinate.

Ten candidate lines were written and judged against the judge brief
(`CANDIDATES.md`); this one won because its joke turns on the agent's own
defining flaw — hallucination, cured by its own disaster — which no other
entry in the field uses.

## Run it

```sh
python3 main.py
```
